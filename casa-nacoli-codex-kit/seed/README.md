# Seed data

- `4` categorias principais.
- `27` produtos agrupados por conceito.
- `29` avaliações.
- `site-config.json` contém placeholders que precisam ser confirmados.
- `product.schema.json` descreve o formato base.

## Importante

O catálogo agrupa variações para evitar cards repetidos. O site final pode migrar estes JSON para Content Collections, desde que:

- preserve os campos e regras;
- mantenha validação;
- continue simples de editar;
- não duplique preços em componentes.
