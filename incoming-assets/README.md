# Incoming assets

Coloque aqui os arquivos antes de iniciar a implementação.

## Brand

`incoming-assets/brand/`

Inclua, quando disponível:

- logo principal;
- logo para fundo claro;
- logo para fundo escuro;
- símbolo isolado;
- arquivos vetoriais;
- manual de marca.

## Products

`incoming-assets/products/`

Os nomes podem ser simples, mas quanto mais descritivos, melhor:

- `caneca-magica-01.jpg`
- `cartao-visita-01.jpg`
- `camiseta-dtf-empresa-01.jpg`

O Codex deve organizar os arquivos sem apagar originais automaticamente.
